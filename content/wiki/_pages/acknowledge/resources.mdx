## 金币

金币是服务器中的通用货币，可以用于和别人交易、锻造装备等诸多用途。

| 获取来源 | 描述                       | 提示                         |
| -------- | -------------------------- | ---------------------------- |
| 每日签到 | 在主城进行每日签到         | 一天只能领一次               |
| 每日任务 | 完成每日刷新的任务         | 不同的任务获得的金币数量不同 |
| 钓鱼     | 参与一天四次的钓鱼岛活动   | 比赛结束前不要离开场地哦     |
| 副本     | 进入副本闯关杀敌           | 每闯过一关就有金币袋奖励     |
| 主城回收 | 在主城向商人出售物资       | 收购价格和物品每日都会变动   |
| 称号     | 完成称号任务               | 不同的称号有不同量的金币奖励 |
| 阶级     | 达成升级目标后进阶获取奖励 | 越高的阶级给的奖励越丰厚     |
| 在线奖励 | 在线到一定时长可以领取金币 | 确保在第二天之前领完         |
| 财富月卡 | 每天都可以领取金币         | 要花费水晶购买才可以领取     |

## 水晶

水晶是服务器中的另一种通用货币，用于购买会员、通行证、月卡或者是其他稀有物品。

| 获取来源 | 描述                         | 提示                         |
| -------- | ---------------------------- | ---------------------------- |
| 每日签到 | 每日签到第一名有额外水晶奖励 | 如果有多人同时第一名都能获得 |
| 每日任务 | 完成每日刷新的稀有、传说任务 | 不同的任务获得的水晶数量不同 |
| 钓鱼     | 参与一天四次的钓鱼岛活动     | 比赛结束前不要离开场地哦     |
| 副本     | 闯过副本之后随机给予奖励     | 部分副本需要通过额外挑战     |
| 称号     | 完成称号任务                 | 不同的称号有不同量的水晶奖励 |
| 阶级     | 达成升级目标后进阶获取奖励   | 越高的阶级给的奖励越丰厚     |
| 在线奖励 | 在线到一定时长可以领取水晶   | 确保在第二天之前领完         |
| 财富月卡 | 每天都可以领取水晶           | 要花费水晶购买才可以领取     |

## 疲劳值

在服务器中挑战副本会消耗你的疲劳值。

| 获取来源 | 描述                         | 提示                           |
| -------- | ---------------------------- | ------------------------------ |
| 自动恢复 | 每一小时恢复 10 点疲劳值     | 需要你保持游戏在线             |
| 每日任务 | 完成每日刷新的任务           | 不同的任务获得的疲劳值数量不同 |
| 在线奖励 | 在线到一定时长可以领取疲劳值 | 确保在第二天之前领完           |

## 职业等级 & 经验

职业经验用于提升职业等级，每 1000 经验提升一级，升级能获得更多技能的使用权限等。

| 获取来源 | 描述                           | 提示                             |
| -------- | ------------------------------ | -------------------------------- |
| 挂机池   | 每五分钟掉落职业经验           | 普通挂机池给 30，会员挂机池给 60 |
| 副本     | 闯过副本之后可获得职业经验     | 简单副本给 1000，困难副本给 2000 |
| 魔塔     | 在魔塔击杀怪物获得职业经验     | 不同层数给的职业经验不同         |
| 称号     | 完成称号任务                   | 不同的称号有不同量的职业经验奖励 |
| 每日任务 | 完成每日刷新的任务             | 不同的任务获得的职业经验数量不同 |
| 在线奖励 | 在线到一定时长可以领取职业经验 | 确保在第二天之前领完             |
