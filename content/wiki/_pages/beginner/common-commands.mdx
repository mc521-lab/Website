> 前情提要：\
> `[ ]` 表示必填项，`( )` 表示选填项\
> 基本没有什么要手动打的指令，80%的功能只需要在主菜单内点击即可！\
> 如果有遗漏哪些指令，请联系服主补充！补充一条奖励 10000 金币

## 基础

| 指令                                                                | 作用                            |
| ------------------------------------------------------------------- | ------------------------------- |
| <MyCopyButton text="/tpa [玩家名]" copyText="/tpa " />              | 申请传送到指定玩家              |
| <MyCopyButton text="/tpahere [玩家名]" copyText="/tpahere " />      | 申请指定玩家传送到你            |
| <MyCopyButton text="/back" />                                       | 返回到上一个传送点              |
| <MyCopyButton text="/msg [玩家名]" copyText="/msg " />              | 对玩家进行私聊                  |
| <MyCopyButton text="/pay [玩家名] [金币数]" copyText="/pay " />     | 给指定玩家转账金币              |
| <MyCopyButton text="/yx send [玩家名]" copyText="/yx send " />      | 将手中的物品发送到玩家邮箱      |
| <MyCopyButton text="/ca sell [价格] [数量]" copyText="/ca sell " /> | 将手中的物品上架到全球市场      |
| <MyCopyButton text="/rtp" />                                        | 随机传送 (适用于资源区、生存区) |

## 特殊指令

| 指令                                                                   | 作用                                                 |
| ---------------------------------------------------------------------- | ---------------------------------------------------- |
| <MyCopyButton text="/gb" />                                            | 开 / 关 屏幕右侧计分板                               |
| <MyCopyButton text="/sb1" />                                           | 开 / 关 屏幕右下侧属性表                             |
| <MyCopyButton text="/music search [歌名]" copyText="/music search " /> | 点一首全服都能听到的歌曲 （免费）                    |
| <MyCopyButton text="/music stop" />                                    | 暂停当前播放的歌曲                                   |
| <MyCopyButton text="/music mute" />                                    | 永久听不到别人点的歌曲 （想解除的话 再输入一次就行） |
