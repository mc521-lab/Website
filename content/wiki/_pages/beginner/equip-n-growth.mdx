装备是角色战斗力的重要组成部分。<br/>通过获取、强化与合理搭配武器、护甲、宝石与饰品，可显著提升输出、生存与团队贡献。<br/>本章介绍装备的基本规则、品质体系与成长方向，并提供图鉴入口以便查阅详细属性。

## 品质体系

装备按品质分为 D、C、B、A、S 五个等级。品质越高，基础属性、耐久与宝石槽位通常越优。

| 品质 | 大致定位 | 特点                                 |
| ---- | -------- | ------------------------------------ |
| D    | 入门     | 基础属性较低，宝石槽较少             |
| C    | 进阶     | 属性提升明显，适合过渡               |
| B    | 主力     | 综合性能均衡，常见于中期             |
| A    | 高阶     | 属性显著增强，宝石容量更高           |
| S    | 顶级     | 最高属性与最多宝石支持，获取难度最高 |

同一职业的装备在命名与属性侧重点上保持一致，便于成套搭配。

## 武器

武器是输出的核心。不同职业对应专属武器，主要属性包括攻击伤害、攻击速度、暴击率与暴击伤害，以及耐久度。高品质武器通常拥有更多宝石槽与更高宝石容量。

**职业武器示例（按品质递进）：**

- **刺客**：暗卒之刃（D）→ 隐匿之刃（C）→ 夜行之刃（B）→ 诡影之刃（A）→ 刺魂之刃（S）<br/>
  侧重攻击速度与暴击，适合爆发输出。

- **牧师**：信徒之杖（D）→ 圣洁之杖（C）→ 光辉之杖（B）→ 守护之杖（A）→ 教皇之杖（S）<br/>
  兼顾输出与辅助需求。

- **射手**：弓卒之刃（D）→ 猎手之刃（C）→ 鹰眼之刃（B）→ 苍穹之刃（A）→ 后羿之刃（S）<br/>
  强调远程精准与机动配合。

- **法师**：学徒之杖（D）→ 术师之杖（C）→ 魔导之杖（B）→ 贤者之杖（A）→ 法神之杖（S）<br/>
  高攻击伤害，配合技能形成范围压制。

- **战士**：士卒之刃（D）→ 骑士之刃（C）→ 将军之刃（B）→ 领袖之刃（A）→ 战神之刃（S）<br/>
  稳健的攻击与生存平衡，适合前排持续作战。

详细数值与宝石槽信息请参阅武器图鉴。

## 护甲

护甲提供基础护甲值、耐久，以及额外效果（如防御、生命上限、法力上限、耐力、格挡、闪避、移速等）。<br/>不同职业的护甲套装侧重点不同：

- **战士**：侧重最大生命与防御，适合承伤。
- **刺客**：侧重防御与移动速度，提升机动与生存。
- **射手**：侧重防御、法力/耐力与闪避，兼顾风筝与续航。
- **法师**：侧重防御、法力、耐力与格挡，强化施法安全。
- **牧师**：侧重最大生命、防御、法力与耐力，提升团队续航能力。

护甲同样分为头盔、胸甲、护腿、靴子四个部位，<br/>建议优先凑齐同品质同系列套装以获得额外的属性收益。高品质护甲拥有更高的宝石容量。

## 宝石

宝石可镶嵌于武器或护甲的空槽中，进一步强化特定属性。<br/>镶嵌存在成功率，品质越高成功率越低，消耗也相应增加。失败通常会消耗宝石。

宝石类型及其主要效果：

| 类型     | 主要效果方向         |
| -------- | -------------------- |
| 暴击宝石 | 暴击率、暴击伤害     |
| 冰灵宝石 | 最大法力、法力回复   |
| 风语宝石 | 最大耐力、耐力回复   |
| 焚心宝石 | 最大生命、生命回复   |
| 灰烬宝石 | 闪避、防御           |
| 灵魂宝石 | 攻击伤害、对怪物伤害 |

宝石同样有 D 至 S 品质。低品质宝石成功率高、消耗低，适合初期过渡；<br/>高品质宝石属性上限更高，但风险与成本显著增加。建议根据当前装备槽位与职业需求选择镶嵌方向。

## 饰品

饰品包括戒指（左右）、手套、手镯、项链以及特殊密宝。大部分饰品带有随机属性池，部分为固定或高权重组合。

- **普通饰品**：提供攻击、生命、防御、暴击、法力、耐力、减伤等随机属性。
- **密宝**（特殊）：属性更强，常包含多条核心效果，是提升战力的重要来源。

不同职业的饰品命名与属性倾向有所区分，例如刺客更侧重攻击与移速相关，战士更侧重生命与防御相关。<br/>饰品可与武器、护甲形成互补，建议优先补足职业短板。

## 成长建议

1. **品质优先**：初期以 C、B 品质过渡，中期追求 A 品质成套，后期再冲击 S 品质。
2. **成套搭配**：尽量使用同一品质的武器与护甲，属性更协调。
3. **宝石规划**：先填满空槽，再逐步替换为更高品质宝石。注意成功率与消耗，避免盲目追求顶级。
4. **属性侧重**：
    - 输出职业优先攻击、暴击、对怪伤害。
    - 坦克优先生命、防御。
    - 辅助优先法力、生命与团队相关属性。
5. **循序渐进**：通过副本、任务、活动逐步积累，不要急于一步到位。

装备系统与职业定位紧密相关。合理搭配后，再结合技能与走位，即可在各类战斗中发挥出大作用。<br/>更多具体数值，请直接查阅对应图鉴页面，或前往主城锻造处查询。
