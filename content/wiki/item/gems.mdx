君庭阁服务器中的宝石系统为装备提供额外属性加成。不同宝石拥有不同的属性方向，同一颗宝石也有 C / B / A / S 四个品质等级，品质越高属性越强。

## 品质说明

| 品质 | 说明             | 属性范围 |
| ---- | ---------------- | -------- |
| C 级 | 随机一个属性     | 最低     |
| B 级 | 随机一到两个属性 | 较低     |
| A 级 | 随机一到两个属性 | 较高     |
| S 级 | 两个属性         | 最高     |

## 获取方式

宝石可通过以下途径获得：

- 副本掉落
- 活动奖励
- 玩家交易
- 合成系统

> 提示：S 级宝石极为稀有，建议优先用于核心装备。
