君庭阁服务器中的饰品系统为角色提供多样化的属性加成。饰品分为多个部位，不同职业拥有专属命名的饰品套装。

## 饰品部位

| 部位    | 说明                  |
| ------- | --------------------- |
| 手镯    | 提供体力/法力加成     |
| 项链    | 提供 PVP/PVE 伤害减免 |
| 手套    | 提供暴击相关属性      |
| 戒指-左 | 提供生命/减伤属性     |
| 戒指-右 | 提供攻击相关属性      |
| 秘宝    | 提供综合属性组合      |
