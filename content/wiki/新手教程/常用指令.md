> 注：基本没有什么要手动打的指令，80% 的功能只需要在主菜单内点击即可！\
> 如果有遗漏哪些指令，请联系服主补充！补充一条奖励 10000 金币

## 基础

| 指令               | 作用                       |
| ------------------ | -------------------------- |
| `/tpa 玩家`          | 申请传送到指定玩家         |
| `/tpahere 玩家`      | 申请指定玩家传送到你       |
| `/back`              | 返回到上一个传送点         |
| `/m 玩家`            | 对玩家进行私聊             |
| `/pay 玩家 金币`     | 给指定玩家转账金币         |
| `/yx send 玩家`      | 将手中的物品发送到玩家邮箱 |
| `/ca sell 价格 数量` | 将手中的物品上架到全球市场 |

## 特殊



| 指令               | 作用                                               |
| ------------------ | -------------------------------------------------- |
| `/gb`               | 开/关 屏幕右侧计分板                               |
| `/sb1`              | 开/关 屏幕右下侧属性表                             |
| `/music search 歌名` | 点一首全服都能听到的歌曲 （免费）                  |
| `/music stop`       | 暂停当前播放的歌曲                                 |
| `/music mute`       | 永久听不到别人点的歌曲 （想解除的话 点一首歌即可） |
