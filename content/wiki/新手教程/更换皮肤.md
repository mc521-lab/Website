## **无正版账号的情况下**

方法一 : 使用本服自带的皮肤库 在游戏内输入指令 `/skins`

方法二 ：

1. 打开这个网站 [皮肤大全链接](https://namemc.com/minecraft-skins/trending)
2. 在网站内找到你心仪的皮肤，然后点击皮肤上方的 ID

![](/assets/wiki/新手教程/更换皮肤/1731490954235-25f7e69a-0f9a-4103-a660-4f1f162ba7a4.png)

3. 点进去后，会看到下方有很多不一样的 ID，我们随便选择一个 ID 然后点进去，我这里选择的是 Tek 和 LeSqueegee

![](/assets/wiki/新手教程/更换皮肤/1731491993425-716d15fa-e4fc-4f07-abe2-35951ab93e89.png)

4. 点进去后，我们要注意一点，就是这个 ID 的第一个皮肤，必须跟你选择的皮肤是相同的\
   在这两个 ID 中，明显 Tek 的皮肤是正确的 而 LeSqueegee 的皮肤是错误的

<div class="flex gap-4">
<img src="/assets/wiki/新手教程/更换皮肤/1731491762004-571be989-2a99-44ba-812d-27bb0b15f0d2.png" alt="Tek" />
<img src="/assets/wiki/新手教程/更换皮肤/1731491869537-49e3dc19-ff6d-4b29-b022-41aabb0e489c.png" alt="LeSqueegee" />
</div>

5. 最后我们选择正确的 ID 然后在游戏内输入 `/skin Tek` 即可更换皮肤 这样就成功咯！
