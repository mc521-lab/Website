## 简述

公会神石每 10 分钟会为公会增加 `公会在线人数 × 神石等级` 点 <span style="color: #2F4BDA">**公会活跃**</span>，同时为公会成员提供辅助 Buff。

升级公会神石可以提高公会活跃的获得速度，并增强 Buff 效果。

需要注意的是，公会活跃神石和 Buff 神石的等级互不影响，升级其中一个不会改变另一个的等级。

神石升级操作 仅限公会 <span style="color: #7E45E8;">**会长**</span> 或 <span style="color: #F3BB2F;">**副会长**</span> 执行。升级按钮位于公会系统的神石页面，点击进入即可操作。

将鼠标悬停在按钮上，可以查看升级所需条件。达成条件后，点击按钮即可完成升级。

## 升级条件

升级到指定等级需要花费对应资金

| 对应等级 | 公会资金 |
| :------: | :------: |
| 1 (默认) |    -     |
|    2     |   1000   |
|    3     |   3000   |
|    4     |   5000   |
|    5     |  10000   |
|    6     |  15000   |
|    7     |  20000   |
|    8     |  25000   |
|    9     |  30000   |
|    10    |  50000   |
